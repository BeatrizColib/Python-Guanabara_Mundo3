# 🐍 Python - Curso em Vídeo (Mundo 3)

Este repositório contém os exercícios resolvidos por mim, Ana Beatriz, do **Mundo 3** do curso de Python do professor **Gustavo Guanabara**, oferecido no [Curso em Vídeo](https://www.cursoemvideo.com/).

---

## 📚 Sobre o Curso

O **Mundo 3** aborda conceitos fundamentais da programação com foco em:
- Estruturas de repetição (`while`)
- Condições dentro do laço
- Interrupções de laço (`break`, `continue`)
- Laços infinitos e controle de fluxo
- Práticas com menu interativo, validação de entrada e mais!

---

## 📁 Organização dos arquivos

Os arquivos estão organizados por número da aula ou exercício, por exemplo:

ex001.py → Primeiro exercício do Mundo 3
ex002.py → Segundo exercício, e assim por diante...
